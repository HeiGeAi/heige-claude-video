# 动效技法库（animation-techniques）

这套系统**不用音效**：两个声音叠在一起观感很差（实测结论）。成片只有人声和背景音乐两层，原来卡音效的特殊场景全部用视觉强调动效来做。本篇是强调动效的技法清单和克制规则。

## 六类视觉强调（锚在口播念到关键词的时间点）

| 场景 | 动效 |
|---|---|
| 揭晓、答案出现 | 冲击缩放（scale 0.85 到 1.08 再回弹到 1，spring 弹性）+ 一圈光晕扩散，背景其余元素同时压暗 30% |
| 数字、价格、百分比 | 数字滚动计数，落定时整块描边光扫一次 + 短暂色彩脉冲（主色或琥珀） |
| 对比、反转 | 分屏推拉或翻牌；错的一侧变灰、抖动后收缩，对的一侧放大高亮 |
| 警告、风险 | 红色描边呼吸 2 次 + 轻微镜头震动（位移不超过 6 像素、0.3 秒内衰减），不闪屏 |
| 转场、段落切换 | 镜头推进或横移加运动模糊，粒子或线条带领视线进入下一场景 |
| 关键词上屏 | 逐字弹入、下划线划出、荧光笔涂抹，一屏只强调一个词 |

## 克制规则（强调服务理解，不是炫技）

- 同一句里只用一种强调动效。
- 相邻两次强调间隔至少 2 秒。
- 全片震动类效果不超过 3 次。
- 每处强调看完能指出「这一下在强调哪个词」；指不出来就删。
- 自查：拼图和单帧里能看到每个强调点的峰值帧。

## 常用图解模式（按本集内容选用，不整集照搬）

讲机制、原理类内容反复用得上的图解单元，每集按内容重新设计：

- **流程链**：节点加箭头逐步点亮，前一步的结果变成下一步的开头，最后合起来看全貌（原理拆解万能骨架）。
- **概率条**：一排候选条随口播动态重新分配宽度，讲「模型在猜下一个字」这类概率问题的核心图。
- **对话窗**：聊天气泡逐条弹入，AI 的回答打字机式出现；用户消息和 AI 回复用左右和颜色区分。
- **数据卡**：一个大数字 + 一行说明，数字滚动到位后描边光扫过；来源和日期以小字标在卡角。
- **官方原文卡**：地址栏 + 网页截图 + 关键句琥珀高光扫过 + 中文翻译 + 来源标注；高光时间卡在口播念到这句。
- **对比卡**：左右两列同样结构，差异项用强调色和动效点出；避免一长串文字对一长串文字。
- **地图/星系**：知识点作为节点散布，讲到的节点连线亮起；节点数量控制在几十个内，超过就分场景。
- **时间轴**：横向时间轴逐步推进，事件节点弹出；配合「年份程序排版」避免手写错。

## 性能与稳定性

- 一帧内的重复绘制要算成本：几千个粒子的场景，先测一帧耗时再铺开；光晕只给标记过的粒子画。
- 拖尾、辉光这类多遍绘制的元素，用同一位置函数在不同 t 值重算，不要保存历史状态。
- 渲染中偶发的花屏帧（截图没画完）用「花屏扫描 + 单帧重渲替换」处理，不要整片重渲：整片重渲会出新位置的坏帧。
- 渲染并发可调；和配音等大内存任务不要同时跑。
